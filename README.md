# SpeakerCard-1M Double-Blind Project Page

This directory is the anonymous review version of the SpeakerCard-1M project page.

## Files

- `index.html`: self-contained anonymous landing page.
- `assets/style.css`: visual styling shared with the public page plus double-blind review components.
- `assets/pipeline.png`: project pipeline figure placeholder/source image.
- `.nojekyll`: GitHub Pages passthrough marker.

## Double-Blind Safety Notes

- No author names, affiliations, personal accounts, project IDs, or cluster paths are included.
- Public GitHub, Hugging Face, arXiv, and checkpoint links are intentionally withheld.
- The page uses `noindex,nofollow` to reduce accidental indexing during review.
- The camera-ready/public page can be restored from `SpeakerCard-1M-page/`.

## Deployment

Deploy the contents of this directory, not the non-anonymous `SpeakerCard-1M-page/`, during double-blind review.
